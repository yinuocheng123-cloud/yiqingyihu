# 一清一护全球严选 OPC 操作系统

## 项目说明

这是一个围绕客户、订单、回访、复购、会员、代理、内容沉淀构建的轻量化业务中台。

## 当前阶段

- 已完成核心 MVP 模块落地，可直接承接个人日常业务
- 已具备客户、订单、发货、回访、会员、伙伴、内容素材、首页看板、系统设置与日志查看
- 已提供数据库初始化脚本和默认基础配置种子

## 目录说明

- `apps/server`：NestJS 后端服务
- `apps/web`：React 后台前端
- `custom/notes`：迭代记录
- `docker`：部署相关配置

## MVP 已覆盖的模块

- 登录与权限
- 客户管理
- 订单管理
- 发货履约
- 回访复购
- 会员管理
- 伙伴管理
- 内容素材管理
- 首页经营看板与待办提醒
- 系统设置与操作日志

## 首次启动

1. 安装依赖：`npm install`
2. 复制环境变量：`apps/server/.env.example` 到 `apps/server/.env`
3. 准备 PostgreSQL，并确认 `DATABASE_URL` 可连接
4. 执行数据库初始化：`npm run db:setup`
5. 启动后端：`npm run dev:server`
6. 启动前端：`npm run dev:web`

## 默认账号

- 账号：`admin`
- 密码：`Admin123456`

## 默认基础配置

初始化脚本会自动写入以下基础配置：

- 来源渠道：淘宝、小程序、小红书、微信私聊、企业微信
- 客户类型：个人客户、家庭客户、企业客户、潜在代理
- 产品类别：清洁类、护理类、严选进口周边
- 内容平台：小红书、朋友圈、视频号、公众号

## 推荐使用顺序

1. 在系统设置中确认基础配置是否符合你的实际业务口径
2. 先录入客户
3. 再录入订单和发货
4. 用回访模块做三次跟进和复购判断
5. 将高价值客户转为会员或伙伴
6. 在内容素材模块中沉淀客户原话和反馈
7. 每天先看首页待办，再处理各模块事务
